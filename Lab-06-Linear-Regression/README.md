# Lab 06 - Linear Regression

## Objective
To implement Linear Regression using Python and evaluate the model's performance using regression metrics.

## Dataset
The dataset contains 6 samples provided in the Machine Learning Mid-Term Examination.

| Sample | Actual Y |
|--------|----------|
| 1 | 8 |
| 2 | 10 |
| 3 | 12 |
| 4 | 14 |
| 5 | 16 |
| 6 | 18 |

## Implementation
Linear Regression is implemented using Python and Scikit-learn in Google Colab.

The model learns from the given sample data and predicts the target values.

## Evaluation Metrics
1. Mean Absolute Error (MAE)
2. Mean Squared Error (MSE)
3. Root Mean Squared Error (RMSE)
4. R-squared Score (R²)

## Technologies Used
- Python
- NumPy
- Scikit-learn
- Google Colab
