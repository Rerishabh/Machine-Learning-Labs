# Lab 07: Statistical Analysis of Housing Dataset

## Aim
To perform statistical analysis on the Housing dataset using Python.

## Dataset
- Dataset: Housing.csv
- Total Records: 545
- Total Features: 13

## Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Experiments Performed
1. Loaded and explored the Housing dataset.
2. Calculated mean, median, mode, and standard deviation.
3. Calculated the correlation matrix.
4. Visualized the correlation matrix using a heatmap.
5. Calculated the covariance matrix.
6. Visualized the covariance matrix using a heatmap.

## Files
- `Lab07_Statistical_Analysis.ipynb` - Jupyter Notebook containing the code and outputs.
- `Lab-07-Statistical-Analysis.pdf` - PDF report of the experiment.
- `Housing.csv` - Dataset used for analysis.

## Conclusion
Statistical measures, correlation, and covariance were calculated
for the Housing dataset. Heatmaps were used to visualize relationships
between the variables.
